# 数据关系设计

> 14 张表的 ER 关系与级联说明。  
> 关联文档：[Supabase数据库设计.md](./Supabase数据库设计.md)

## ER 关系总览

```
auth.users (1) ─── (N) profiles
auth.users (1) ─── (N) projects
auth.users (1) ─── (N) ai_generations

projects (1) ─── (1) stories           [一对一]
projects (1) ─── (1) visual_styles      [一对一]
projects (1) ─── (1) scripts            [一对一]
projects (1) ─── (N) characters         [一对多]
projects (1) ─── (N) locations          [一对多]
projects (1) ─── (N) episodes           [一对多]
projects (1) ─── (N) ai_generations     [一对多]

episodes (1) ─── (N) scenes             [一对多]
locations (1) ─── (N) scenes            [一对多，scenes.location_id]
scenes (1) ─── (N) shots                [一对多]

characters ←──→ shots                   [多对多，shots.character_ids jsonb]

shots (1) ─── (N) prompts               [一对多，shot 级 Prompt]
episodes (1) ─── (N) prompts            [一对多，集级 Prompt（剪辑）]

prompts (1) ─── (N) prompt_versions     [一对多，版本链]

prompt_templates                        [独立表，无外键关联]
```

---

## 核心关系详解

### characters 与 shots（多对多）

```
shots.character_ids (jsonb 数组) → characters.id
```

| 项 | 说明 |
|----|------|
| 关系类型 | 多对多 |
| 存储方式 | shots.character_ids = `["uuid-1", "uuid-2"]` |
| 不用关联表原因 | 关系简单，jsonb 查询方便，镜头删除不影响角色 |
| 查询方式 | `SELECT * FROM characters WHERE id = ANY(shot.character_ids::uuid[])` |
| 级联 | 角色删除时，不自动清理 shots 中的 character_ids（需应用层处理） |

### locations 与 scenes（一对多）

```
scenes.location_id (外键) → locations.id
```

| 项 | 说明 |
|----|------|
| 关系类型 | 一对多 |
| 级联策略 | `ON DELETE SET NULL`：场景资产删除时，scenes.location_id 置空 |
| 引用链 | `shot.scene_id → scene.location_id → location.visual_prompt` |

### visual_styles 与 projects（一对一）

```
projects.visual_style_id (外键) → visual_styles.id
```

| 项 | 说明 |
|----|------|
| 关系类型 | 一对一 |
| 级联策略 | `ON DELETE SET NULL` |
| 注意 | projects 表有 visual_style_id 外键；visual_styles 表也有 project_id 外键。两者指向同一关系。建表时需注意循环依赖，先建 visual_styles 再加 projects 外键。 |

> **解决循环依赖**：先创建 visual_styles 表（不含 projects 外键），再创建 projects 表（含 visual_style_id 外键），最后 `ALTER TABLE visual_styles ADD CONSTRAINT ...`。或用 `projects.visual_style_id` 单向引用。

### prompts 与 prompt_versions（一对多）

```
prompt_versions.prompt_id (外键) → prompts.id
```

| 项 | 说明 |
|----|------|
| 关系类型 | 一对多 |
| 级联策略 | `ON DELETE CASCADE`：Prompt 删除时所有版本级联删除 |
| 版本管理 | 每次 AI 生成或用户保存创建新 version，旧 version 保留 |
| current 标记 | 同一 prompt_id 下只有一个 `is_current=true` |

## 完整关系矩阵

| 父表 | 子表 | 外键字段 | 关系 | 级联 |
|------|------|----------|------|------|
| auth.users | profiles | id | 1:1 | CASCADE |
| auth.users | projects | user_id | 1:N | CASCADE |
| auth.users | ai_generations | user_id | 1:N | CASCADE |
| projects | stories | project_id | 1:1 | CASCADE |
| projects | visual_styles | project_id | 1:1 | CASCADE |
| projects | scripts | project_id | 1:1 | CASCADE |
| projects | characters | project_id | 1:N | CASCADE |
| projects | locations | project_id | 1:N | CASCADE |
| projects | episodes | project_id | 1:N | CASCADE |
| visual_styles | projects | visual_style_id | 1:1 | SET NULL |
| episodes | scenes | episode_id | 1:N | CASCADE |
| locations | scenes | location_id | 1:N | SET NULL |
| scenes | shots | scene_id | 1:N | CASCADE |
| shots | prompts | shot_id | 1:N | CASCADE |
| episodes | prompts | episode_id | 1:N | CASCADE |
| prompts | prompt_versions | prompt_id | 1:N | CASCADE |

## 数据层级图

```
Level 0: auth.users
Level 1: profiles, projects, ai_generations
Level 2: stories, visual_styles, scripts, characters, locations, episodes
Level 3: scenes
Level 4: shots
Level 5: prompts
Level 6: prompt_versions
Independent: prompt_templates
```

> 建表顺序应从 Level 0 到 Level 6 依次创建，避免外键依赖错误。
