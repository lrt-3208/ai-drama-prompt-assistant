## 核心组件说明

### PromptWorkspace

Prompt 工作台主体，组合左侧镜头信息 + 右侧 Prompt 生成区。

```
Props: { shotId: string }
├── ShotInfoPanel（左侧：镜头信息 + 上下文引用）
│   ├── 场景/人物/动作/情绪/摄影
│   └── ContextReference（引用的角色/场景/风格）
├── PromptTypeTabs（右侧顶部：图片/视频/声音标签页）
├── PlatformSelector + LanguageSelector
├── GenerateButton
├── PromptOutput（可编辑文本区）
├── CopyButton + SaveButton
└── VersionHistory
```

### CharacterAssetCard

角色资产卡片，展示角色信息 + visual_prompt。

```
┌────────────────┐
│ 林晚    [编辑]  │
│ 25岁 · 女       │
│ ─────────────  │
│ visual_prompt:  │
│ 25岁亚洲女性... │
│ [重新生成]      │
└────────────────┘
```

### ShotCard

镜头卡片，展示镜头信息 + Prompt 快捷入口。

```
┌──────────────────────┐
│ Shot 1   [编辑] [复制] │
│ 女主站在医院门口      │
│ 林晚 · 绝望 · 中景    │
│ [图片Prompt] [视频Prompt] [声音Prompt] │
└──────────────────────┘
```

## 组件 Props 约定

```typescript
// ProjectCard
interface ProjectCardProps {
  project: Project;
  onEdit: (id: string) => void;
  onDelete: (id: string) => void;
  onClick: (id: string) => void;
}

// CharacterAssetCard
interface CharacterAssetCardProps {
  character: Character;
  onEdit: (id: string) => void;
  onRegeneratePrompt: (id: string) => void;
}

// PromptWorkspace
interface PromptWorkspaceProps {
  shotId: string;
}

// ShotCard
interface ShotCardProps {
  shot: Shot;
  onEdit: (id: string) => void;
  onGeneratePrompt: (shotId: string, type: PromptType) => void;
}
```
