# 页面设计

> 路由设计与页面布局。  
> 关联文档：[组件设计.md](./组件设计.md) | [UI规范.md](./UI规范.md)

---

## 页面总览

| 页面 | 路由 | 说明 | 优先级 |
|------|------|------|--------|
| 登录/注册 | `/login` | 邮箱密码登录注册 | P0 |
| Dashboard | `/dashboard` | 项目列表 + 创建 | P0 |
| 项目工作台 | `/projects/[id]` | 项目首页（概览+进度） | P0 |
| 剧本页 | `/projects/[id]/script` | 剧本生成与编辑 | P0 |
| 资产中心 | `/projects/[id]/assets` | 角色/场景/风格库 | P0 |
| 分镜页 | `/projects/[id]/storyboard` | 分镜列表与编辑 | P0 |
| Prompt 工作台 | `/projects/[id]/prompts/[shotId]` | 单镜头 Prompt 生成 | P0 |
| 导出页 | `/projects/[id]/export` | 导出/剪辑建议 | P1 |
| 设置 | `/settings` | AI 模型配置 | P1 |

---

## 项目工作台结构

```
项目工作台 /projects/[id]
├── 项目首页（概览：进度/状态/快捷入口）
├── 剧本（故事输入 + AI 生成 + 编辑）
├── 资产中心
│     ├── 角色库
│     ├── 场景库
│     └── 视觉风格
├── 分镜（Episode → Scene → Shot 列表）
├── Prompt 工作台（单镜头：图片/视频/声音/剪辑 Prompt）
└── 导出（剪辑建议 + 批量导出）
```

## 交互说明

| 交互 | 说明 |
|------|------|
| 标签页切换 | 客户端状态切换，无页面刷新 |
| AI 生成 | 点击后 Loading 态，成功后填充内容 |
| 复制 Prompt | 一键复制 + Toast 提示 |
| 编辑保存 | 编辑后保存为新版本 |
| 资产引用展示 | Prompt 工作台显示引用的角色/场景/风格 |
| 历史版本 | 下拉展开版本列表，可查看/恢复 |
