# 剪辑 Prompt 规范

> 剪辑建议 Prompt 的结构化字段与输出规范。[P1]  
> 关联文档：[Prompt生成架构.md](./Prompt生成架构.md)

---

## Prompt 结构

剪辑 Prompt 描述**某集的剪辑建议**，包含四个维度：

| 维度 | 字段 |
|------|------|
| 镜头排序 | 顺序建议及理由 |
| 字幕建议 | 样式/位置/特殊处理 |
| BGM建议 | 音乐风格/节奏/情绪匹配 |
| 转场建议 | 硬切/叠化/淡入淡出 + 使用场景 |

---

## 输出示例

```
镜头排序：S1-1 → S1-2 → S1-3 → S1-4 → S1-5 → S1-6
排序理由：按时间线推进，开场雨夜远景建立氛围，逐渐推近女主，情绪从绝望到坚定的递进。
字幕建议：简洁白字，底部居中，复仇独白用斜体，字号适中不遮挡画面。关键台词可加粗。
BGM建议：低沉弦乐开场，雷雨音效贯穿全程，高潮段落（S1-4转折处）加入鼓点提升紧张感，结尾留白只有雨声。
转场建议：镜头间用硬切保持紧张节奏；场景转换用雨声叠化2秒；回忆闪回用闪白转场。
```

## 上下文依赖

| 上下文 | 用途 |
|--------|------|
| Episode 内所有 Shots | 镜头序列 → 排序建议 |
| 各 Shot.emotion | 情绪曲线 → BGM 节奏 |
| 各 Shot.cinematography | 摄影语言 → 转场选择 |
| Story.genre | 类型 → 剪辑风格（复仇类快节奏硬切） |

> 剪辑 Prompt 关联 episode_id 而非 shot_id，是集级别的 Prompt。

---

## 存储方式

剪辑 Prompt 存入 `prompts` 表：
- `prompt_type` = 'edit'
- `shot_id` = null（集级别）
- `episode_id` = 目标剧集 ID（prompts 表需新增 episode_id 字段，见数据库设计）

> 设计决策：prompts 表增加可选的 `episode_id` 字段，shot_id 和 episode_id 二选一。
