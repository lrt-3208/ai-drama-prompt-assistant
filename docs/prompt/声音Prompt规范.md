## Prompt 结构

声音 Prompt 描述**角色音色与对白风格**，包含五个维度：

| 维度 | 字段 |
|------|------|
| 角色 | 角色名、声音类型（性别+年龄） |
| 音色 | 低沉/清亮/沙哑/柔和 |
| 情绪 | 愤怒/悲伤/冷静/兴奋 |
| 语速 | 偏慢/正常/偏快 |
| 对白风格 | 简短有力/啰嗦/诗意 |

---

## 输出示例

### 豆包TTS（中文）

```
角色：林晚
声音类型：25岁女性
音色：低沉、冷静、略带沙哑
情绪：压抑的愤怒，带有复仇决心
语速：偏慢，每句结尾有停顿
对白风格：简短有力，不啰嗦，带冷笑
对白文本：（如有 shot.dialogue）
```

### Qwen-TTS（中文）

```
角色：林晚
声音类型：25岁女性
音色：低沉、冷静、略带沙哑

对白风格：简短有力，不啰嗦，带冷笑
对白文本：（如有 shot.dialogue）
```

## 平台适配规则

| 平台 | 语言 | 输出格式 | 说明 |
|------|------|----------|------|
| 豆包TTS | 中文 | 声音描述 + 对白文本 | 描述+文本分离 |
| Qwen-TTS | 中文 | 声音描述 + 对白文本 | 描述+文本分离 |

## 上下文依赖

| 上下文 | 用途 |
|--------|------|
| Character | 角色名/年龄/性别 → 声音类型 |
| Shot.emotion | 情绪 → 声音情绪 |
| Shot.dialogue | 对白文本 |
| Story.genre | 类型 → 对白风格（复仇类简短有力，甜宠类活泼） |

---

## 一致性说明

同一角色的声音描述应跨镜头保持一致：

- 声音类型固定（25岁女性低沉声线）
- 音色固定（低沉、沙哑）
- 情绪可变（跟随镜头情绪变化）
- 语速可变（紧张时偏快，平静时偏慢）

> 未来 V4 接入 TTS API 后，角色可绑定固定音色 ID，实现真正声音一致。
