## prompt_templates 表设计

每个平台对应一条模板记录，存储在 `prompt_templates` 表。

| 字段 | 说明 |
|------|------|
| platform | 平台标识 |
| provider | v2 新增：服务商（openai/volcengine/jimeng/midjourney/flux/comfyui/kuaishou/runway/ltx） |
| prompt_type | image / video / voice / edit |
| language | zh / en |
| output_language | v2 新增：输出语言（zh/en/mixed），控制 Prompt 生成语言风格 |
| system_rule | 平台格式规则（System Prompt 的一部分） |
| input_fields | 需要注入的上下文字段列表 |
| output_format | 输出格式说明 |
| example | 示例 Prompt |
| is_active | 是否启用 |

## 模板使用流程

```
PromptEngine 生成 Prompt
  ↓
ContextBuilder 汇聚上下文
  ↓
查询 prompt_templates WHERE platform=? AND prompt_type=? AND language=? AND is_active=true
  ↓
TemplateAssembler 组装：
  system = template.system_rule + 资产固定 Prompt
  user = 镜头上下文 + "请按{platform}格式生成"
  ↓
AI 生成 → 输出
```

## 新增平台流程

新增一个平台只需：

1. 在 `prompt_templates` 表插入新记录
2. 在前端平台选择器枚举中新增选项
3. 无需修改 Prompt Engine 核心逻辑

**示例 SQL**：
```sql
INSERT INTO prompt_templates (platform, prompt_type, language, system_rule, input_fields, output_format, example, is_active)
VALUES ('new_platform', 'image', 'en', 'NewPlatform规则...', '["characters","location","shot","visual_style"]', '英文关键词格式', '示例Prompt...', true);
```
