# 产品路线图

> V1→V5 版本演进规划。  
> 关联文档：[MVP范围.md](./MVP范围.md)

---

## 版本总览

| 版本 | 定位 | 核心交付 | 优先级 |
|------|------|----------|--------|
| V1 (P0) | Prompt 生成 MVP | 故事→剧本→资产→分镜→图片/视频 Prompt → 复制 | 当前 |
| V1.5 (P1) | Prompt 增强版 | 声音/剪辑 Prompt + 模板系统 + 版本管理 | 次优先 |
| V2 | 图片 API 接入 | 即梦/MJ/Flux/ComfyUI 自动生成图片 | 未来 |
| V3 | 视频 API 接入 | 可灵/Runway/LTX 自动生成视频 | 未来 |
| V4 | 配音 TTS 接入 | 豆包TTS/Qwen-TTS 合成 | 未来 |
| V5 | AI 导演 Agent | 自动编排全链路 + 一键生成短剧 | 远期 |

---

## V1 (P0) — Prompt 生成 MVP

**目标**：完成核心闭环，验证 Prompt 生成 + 一致性资产价值。

**交付内容**：
- 用户认证 + 项目管理
- 故事输入 + AI 剧本生成
- 创作资产中心（角色/场景/视觉风格）
- AI 分镜生成（Episode→Scene→Shot）
- 图片 Prompt（4 平台 ×2 语言，上下文驱动）
- 视频 Prompt（3 平台）
- Prompt 复制

**验证标准**：
- 输入一句话故事，走通全链路到图片/视频 Prompt
- 同一角色在不同镜头的 Prompt 中外貌描述一致
- 9 大平台 Prompt 格式正确可复制

---

## V1.5 (P1) — Prompt 增强版

**目标**：补全 Prompt 类型 + 版本管理 + 模板系统。

**交付内容**：
- 声音 Prompt（豆包TTS/Qwen-TTS）
- 剪辑 Prompt（排序/BGM/转场）
- prompt_templates 模板系统
- prompt_versions 版本管理（历史/恢复）
- 平台模板可配置
- AI 模型切换（DeepSeek/Claude/Kimi/豆包）
- 导出功能（文本/JSON）

---

## V2 — 图片 API 自动生成

**目标**：从"只输出 Prompt"升级为"可自动生成图片"。

**交付内容**：
- 即梦 API 接入
- Midjourney API 接入（Discord Bot / 代理）
- Flux API 接入
- ComfyUI API 接入
- 图片存储到 Supabase Storage
- 镜头卡片展示生成图片
- 批量生成

**架构扩展点**：`AIService.generateImage()` + `ImageProviderAdapter`

---

## V3 — 视频 API 自动生成

**目标**：图生视频，自动化视频生成。

**交付内容**：
- 可灵 API 接入
- Runway API 接入
- LTX API 接入
- 图生视频（图片 + 视频 Prompt → 视频）
- 视频存储 + 预览
- 异步任务管理（轮询/回调）

**架构扩展点**：`AIService.generateVideo()` + `VideoProviderAdapter` + 异步任务表

---

## V4 — 配音 TTS 接入

**目标**：角色音色绑定，自动配音。

**交付内容**：
- 豆包 TTS API 接入
- Qwen-TTS API 接入
- 角色音色固定绑定
- 音频存储 + 预览

---

## V5 — AI 导演 Agent

**目标**：一键生成完整短剧。

**交付内容**：
- AI 导演 Agent 自动决策（镜头顺序/节奏/转场）
- 全链路自动编排（故事→全套素材）
- 质量评分 + 自动重试
- 风格一致性（reference image 引导）
- 成本控制（按预算选模型档位）

---

## 长期扩展

|------|------|

---

## 架构扩展预留总结

| 预留点 | V2 扩展方案 |
|--------|------------|
| AI 模型替换 | Provider 适配器，新增模型实现接口即可 |
| 生成平台扩展 | 模板独立，新增平台加模板不改逻辑 |
| 媒体生成接入 | AIService 新增 generateImage/Video 方法 |
| 异步任务 | API 预留异步生成 + 轮询模式 |
| 存储扩展 | Supabase Storage 直接对接媒体文件 |
| 数据扩展 | 外键关系预留，新增媒体表即可关联 |
