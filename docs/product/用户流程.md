# 用户使用流程

> 端到端用户操作流程，从创建项目到复制 Prompt。  
> 关联文档：[PRD.md](./PRD.md) | [../workflow/AI短剧生产流程.md](../workflow/AI短剧生产流程.md)

---

## 整体流程

```
1. 创建项目
2. 输入故事
3. AI 生成剧本（结构化）
4. 建立创作资产（角色/场景/风格）
5. AI 生成分镜（Episode→Scene→Shot）
6. 生成图片 Prompt（引用资产）
7. 生成视频 Prompt（运动描述）
8. 生成声音 Prompt（角色音色）  [P1]
9. 生成剪辑 Prompt（排序建议）   [P1]
10. 复制 Prompt → 第三方平台制作
```

---

## 步骤详解

### 步骤 1：创建项目

| 项 | 说明 |
|----|------|
| 用户操作 | Dashboard 点击"创建项目"，填写名称、类型、故事简介 |
| AI 处理 | 无 |
| 输出结果 | 项目记录，进入项目首页 |

示例输入：
- 名称：《重生：这一次我要你们全部还回来》
- 类型：复仇/重生
- 简介：林晚在婚礼当天被陷害，重生回到一年前……

### 步骤 2：输入故事

| 项 | 说明 |
|----|------|
| 用户操作 | 在剧本标签页选择输入方式：方式1 输入一句话故事；方式2 粘贴已有剧本 |
| AI 处理 | 无（纯用户输入） |
| 输出结果 | 故事原文存入 stories 表 |

### 步骤 3：AI 生成剧本

| 项 | 说明 |
|----|------|
| 用户操作 | 点击"生成剧本"，选择 AI 模型 |
| AI 处理 | `generateScript()`：故事 → 结构化剧本 |
| 输出结果 | synopsis / genre / characters[] / relationships / worldview / plot_outline[] |

输出示例见 [剧本生成](../workflow/AI短剧生产流程.md#阶段二-剧本生成)。

### 步骤 4：建立创作资产

> **V2 新增核心步骤**，解决多镜头一致性问题。

| 项 | 说明 |
|----|------|
| 用户操作 | 进入"资产中心"标签页，AI 根据剧本自动提取角色/场景，用户可编辑补充 |
| AI 处理 | `generateCharacters()`：剧本 → 角色资产；同时提取场景资产；用户选择/创建视觉风格 |
| 输出结果 | characters[] / locations[] / visual_styles[] 三大资产 |

**资产建立后**：每个角色/场景/风格拥有"固定视觉描述 Prompt"，后续所有 Prompt 生成自动引用。

### 步骤 5：AI 生成分镜

| 项 | 说明 |
|----|------|
| 用户操作 | 选择某一集，点击"生成分镜" |
| AI 处理 | `generateStoryboard()`：剧本+资产 → Episode→Scene→Shot |
| 输出结果 | 每个镜头含 shot_number / description / characters / action / emotion / environment / cinematography / dialogue |

### 步骤 6：生成图片 Prompt

| 项 | 说明 |
|----|------|
| 用户操作 | 在分镜页选择镜头，点击"生成图片 Prompt"，选择平台（即梦/MJ/Flux/ComfyUI）和语言（中/英） |
| AI 处理 | `generateImagePrompt()`：Prompt Engine 汇聚 Shot+Character+Location+Style 上下文 → 平台模板 → AI 生成 |
| 输出结果 | 结构化图片 Prompt，含人物/场景/动作/摄影/风格五维度 |

### 步骤 7：生成视频 Prompt

| 项 | 说明 |
|----|------|
| 用户操作 | 选择镜头，点击"生成视频 Prompt"，选择平台（可灵/Runway/LTX） |
| AI 处理 | `generateVideoPrompt()`：图片描述+镜头信息 → 运动描述 |
| 输出结果 | 镜头运动/人物动作/环境变化/视频参数 |

### 步骤 8：生成声音 Prompt [P1]

| 项 | 说明 |
|----|------|
| 用户操作 | 选择镜头，点击"生成声音 Prompt"，选择平台（豆包TTS/Qwen-TTS） |
| AI 处理 | `generateVoicePrompt()`：角色资产+镜头情绪 → 声音描述 |
| 输出结果 | 角色声音类型/音色/情绪/语速/对白风格 |

### 步骤 9：生成剪辑 Prompt [P1]

| 项 | 说明 |
|----|------|
| 用户操作 | 在"导出"标签页选择某一集，点击"生成剪辑建议" |
| AI 处理 | `generateEditPrompt()`：该集所有镜头 → 剪辑建议 |
| 输出结果 | 镜头排序/字幕/BGM/转场建议 |

### 步骤 10：复制 Prompt

| 项 | 说明 |
|----|------|
| 用户操作 | 在 Prompt 工作台点击"复制"按钮 |
| AI 处理 | 无 |
| 输出结果 | Prompt 文本复制到剪贴板，Toast 提示成功 |

---

## 流程特点

| 特点 | 说明 |
|------|------|
| 非线性 | 可跳过某阶段或回退修改 |
| 可重新生成 | 每步 AI 输出可重新生成，保留历史版本 [P1] |
| 可手动编辑 | 所有 AI 内容可人工编辑 |
| 资产驱动 | 步骤 6-8 的 Prompt 生成依赖步骤 4 的资产 |
