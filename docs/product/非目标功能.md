# 非目标功能（MVP 不做）

> **明确冻结边界：以下功能第一版不做，架构预留但不开发。**  
> 关联文档：[MVP范围冻结.md](./MVP范围冻结.md)

---

## 明确不做清单

| 序号 | 不做功能 | 说明 | 预留方式 |
|------|----------|------|----------|
| 1 | ❌ 图片生成 API | 不调用即梦/MJ/Flux/ComfyUI 生成 API | AIService 预留 generateImage() 方法签名 |
| 2 | ❌ 视频生成 API | 不调用可灵/Runway/LTX 生成 API | AIService 预留 generateVideo() 方法签名 |
| 3 | ❌ TTS 接口 | 不调用豆包TTS/Qwen-TTS 合成 API | prompt_templates 预留 voice 模板记录 |
| 4 | ❌ 自动剪辑 | 不提供视频剪辑功能 | 仅输出剪辑建议 Prompt 文本（P1） |
| 5 | ❌ 自动调用第三方平台 | 用户手动复制 Prompt 到第三方平台 | Prompt 工作台提供复制按钮 |
| 6 | ❌ Agent 自动规划 | 不做 AI 导演 Agent 自动编排 | 架构层不限制，但 MVP 无此模块 |
| 7 | ❌ 多用户协作 | 不做团队协作/权限管理 | RLS 仅做数据隔离，无协作 |
| 8 | ❌ 商业化系统 | 不做会员/积分/付费 | 无计费模块 |
| 9 | ❌ 内容社区 | 不做作品展示/分享/评论 | 无社区模块 |
| 10 | ❌ 移动端适配 | 不做响应式移动端 | 最小宽度 1024px，桌面端优先 |

---

## 架构预留说明

虽然不做，但以下设计点已预留扩展能力：

| 预留点 | 预留方式 | 未来扩展 |
|--------|----------|----------|
| AI Provider 适配器 | AIService + ProviderAdapter 接口 | 新增模型实现接口即可 |
| 平台模板系统 | prompt_templates 表 | 新增平台加模板记录 |
| 媒体生成方法 | AIService 方法签名预留 | V2 实现 generateImage/Video |
| Supabase Storage | 已配置但 MVP 不使用 | V2 存储图片/视频/音频 |
| ai_generations 表 | 记录 AI 调用日志 | V2 用于用量统计 |
| 声音/剪辑 Prompt 类型 | prompt_type 枚举含 voice/edit | P1 补充模板和生成逻辑 |

---

## 冻结原则

> **当 AI Coding Agent 在开发过程中遇到"是否需要实现 XX"的判断时：**
>
> 1. 先查本文件清单，在清单内的**不做**
> 2. 不在清单内的，查 [MVP范围冻结.md](./MVP范围冻结.md)，在必做清单内的**做**
> 3. 两个清单都没有的，**默认不做**，保持当前 MVP 范围
>
> **宁可少做，不可扩大。**
