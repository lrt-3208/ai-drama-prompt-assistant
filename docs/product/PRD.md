# PRD — AI 短剧 Prompt 助手

> 本文件定义产品定位、核心价值、目标边界与非目标。  
> 关联文档：[MVP范围.md](./MVP范围.md) | [用户流程.md](./用户流程.md)

---

## 1. 产品定位

**名称**：AI 短剧 Prompt 助手

**一句话定位**：帮助用户从故事创意出发，系统化生成适用于各主流 AI 工具的高质量 Prompt 的辅助平台，并解决多镜头一致性问题。

**本质**：Prompt 工程辅助工具，不是 AI 内容生成平台。

## 2. 核心价值

| 价值点 | 说明 |
|--------|------|
| 降低 Prompt 编写门槛 | 用户不懂摄影/美术语言，系统自动生成专业 Prompt |
| 多平台适配 | 即梦/MJ/Flux/ComfyUI/可灵/Runway/LTX/豆包TTS/Qwen-TTS 一键适配 |
| 全链路贯通 | 故事→剧本→资产→分镜→图片/视频 Prompt 一站式（声音/剪辑仅留接口） |
| **多镜头一致性** | 通过创作资产中心（角色/场景/风格）保证跨镜头视觉一致 |

## 3. 产品链路

```
故事输入
  ↓
剧本生成（AI 结构化）
  ↓
角色/场景/视觉风格资产建立（创作资产中心）
  ↓
分镜生成（Episode → Scene → Shot）
  ↓
图片 Prompt（引用角色+场景+风格资产）
  ↓
视频 Prompt（运动描述）
  ↓
用户复制 Prompt → 第三方平台制作

  〔声音 Prompt / 剪辑 Prompt：接口预留，MVP 不实现〕
```

## 4. MVP 目标

| 维度 | 目标 |
|------|------|
| 核心能力 | 故事→剧本→资产→分镜→图片/视频 Prompt 全链路 |
| 一致性 | 创作资产中心：角色/场景/风格资产可被 Prompt Engine 引用 |
| AI 能力 | 接入文本 AI（DeepSeek/Claude/Kimi/豆包），Prompt Engine 上下文驱动 |
| Prompt 覆盖 | 图片（4平台×2语言）、视频（3平台）；声音/剪辑仅留接口不实现 |
| 数据管理 | 项目/剧本/资产/分镜/Prompt 的创建/编辑/版本管理 |
| 部署 | Vercel + Supabase Auth + Supabase Database |

## 5. 非目标功能

| 非目标 | 说明 |
|--------|------|
| 图片直接生成 | 不调用即梦/MJ/Flux 生成 API，只输出可复制 Prompt |
| 视频直接生成 | 不调用可灵/Runway/LTX 生成 API |
| 语音直接合成 | 不调用豆包TTS/Qwen-TTS 合成 API |
| 自动剪辑 | 不提供剪辑功能，只输出剪辑建议 Prompt |
| 团队协作 | 不做多用户协作 |
| 付费体系 | 不做会员/积分/付费 |

> **关键边界**：当前版本只负责 Prompt 生成。用户拿到 Prompt 后到第三方平台自行制作。

## 6. 用户画像

- AI 短剧创作者 / 个人内容创作者
- 熟悉即梦、可灵等工具，但 Prompt 编写能力不足
- 需要批量管理多镜头 Prompt 并保持一致性

## 7. 成功指标

| 指标 | 说明 |
|------|------|
| Prompt 生成成功率 | ≥ 95% 的镜头可成功生成有效 Prompt |
| 一致性满意度 | 用户认为多镜头角色/场景"看起来一致"的比例 |
| 链路完成率 | 从故事输入到全套 Prompt 输出的完整走通率 |
| 复制率 | 生成 Prompt 被用户复制的次数 |
