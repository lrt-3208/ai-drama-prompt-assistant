## P0-A：项目基础 + 认证 + Dashboard（3 天）

**目标**：项目脚手架 + 用户认证 + 项目管理。

| 任务 | 验证标准 |
|------|----------|
| 初始化 Next.js + TS + Tailwind + shadcn/ui | 项目可运行 |
| 配置 Supabase（URL/Key/环境变量） | Client 可连接 |
| 执行 migrations：profiles + projects 表 + RLS + 触发器 | 建表成功 |
| 登录/注册页 `/login` | 可注册/登录/登出 |
| 鉴权中间件 | 未登录重定向 |
| Dashboard `/dashboard` | 展示项目列表 |
| 项目 CRUD API + 页面 | 创建/编辑/删除项目 |
| 项目工作台布局（标签页框架） | 可进入项目详情 |

## P0-B：故事 + 剧本生成（2 天）

**目标**：故事输入 + AI 剧本生成。

| 任务 | 验证标准 |
|------|----------|
| 执行 migrations：stories + scripts 表 + RLS | 建表成功 |
| AI 服务层：AIService + DeepSeek 适配器 | 可调用 DeepSeek |
| Prompt 模板：剧本生成 System Prompt | 模板可用 |
| 剧本生成 API `POST /script/generate` | 输入故事→输出结构化剧本 |
| 剧本保存 API `PUT /script` | 可保存编辑 |
| 剧本编辑页：StoryInput + ScriptEditor + CharacterCard + PlotOutlineList | 可输入/生成/编辑/保存 |

## P0-D：分镜生成（3 天）

**目标**：剧本→分镜拆解。

| 任务 | 验证标准 |
|------|----------|
| 执行 migrations：episodes + scenes + shots 表 + RLS | 建表成功 |

| 分镜生成 API `POST /storyboard/generate` | 剧本→Episode→Scene→Shot |

| 分镜页：EpisodeSelector + SceneGroup + ShotCard | 可浏览分镜 |

---

## P0-E：Prompt Engine + 图片/视频 Prompt（4 天）

**目标**：核心 Prompt 生成能力。

| 任务 | 验证标准 |
|------|----------|
| 执行 migrations：prompt_templates + prompts + prompt_versions 表 + RLS | 建表成功 |
| 预置 13 条平台模板数据 | 模板可查询 |
| Prompt Engine：ContextBuilder + TemplateAssembler + OutputProcessor | 可汇聚五重上下文 |
| 图片 Prompt 生成 API `POST /prompts/generate` | 4 平台 ×2 语言可生成 |
| 视频 Prompt 生成 API | 3 平台可生成 |
| Prompt 保存 API `PUT /prompts/[id]` | 可保存编辑 |
| Prompt 工作台页：ShotInfoPanel + PromptTypeTabs + PlatformSelector + PromptOutput + CopyButton | 可生成/编辑/复制 |
| 上下文引用展示：ContextReference | 显示引用的角色/场景/风格 |
| Claude/Kimi/豆包适配器 | 多模型可切换 |

**P0 验收标准**：
- 输入一句话故事 → 走通全链路到图片/视频 Prompt
- 同一角色在不同镜头 Prompt 中外貌描述一致
- 9 大平台 Prompt 格式正确可复制
