## 架构总览

```
┌─────────────────────────────────────────────────────────┐
│                      前端（Next.js）                      │
│  App Router + TypeScript + Tailwind + shadcn/ui          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐   │
│  │ Dashboard │ │ 项目工作台 │ │ 资产中心  │ │Prompt工作台│  │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘   │
├─────────────────────────────────────────────────────────┤
│                   API Route Handlers                     │
│  /api/projects /api/stories /api/scripts ...             │
├─────────────────────────────────────────────────────────┤
│                    Service 层（业务逻辑）                 │
│  ProjectService StoryboardService PromptService ...      │
├─────────────────────────────────────────────────────────┤
│                   Prompt Engine                           │
│  ContextBuilder → TemplateAssembler → AIAdapter → Output  │
├─────────────────────────────────────────────────────────┤
│                    AI 服务层                              │
│  AIService + ProviderAdapter（DeepSeek/Claude/Kimi/豆包） │
├─────────────────────────────────────────────────────────┤
│                   Supabase 后端                           │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐          │
│  │  Auth       │  │ Postgres DB│  │  Storage   │          │
│  │ (JWT会话)   │  │ (14张表+RLS)│  │ (媒体预留)  │          │
│  └────────────┘  └────────────┘  └────────────┘          │
├─────────────────────────────────────────────────────────┤
│                   部署                                    │
│  Vercel（前端+API）  +  Supabase（数据库+认证）            │
└─────────────────────────────────────────────────────────┘
```

---

## 分层职责

| 层 | 职责 | 目录 |
|----|------|------|
| 前端页面 | UI 展示与用户交互 | `app/` |
| API Route | HTTP 请求处理 + 鉴权 | `app/api/` |
| Service 层 | 业务逻辑编排 | `services/` |
| Prompt Engine | 上下文汇聚 + 模板组装 + AI 调用 | `lib/ai/` |
| AI 服务层 | AI 模型适配与调用 | `lib/ai/providers/` |
| 数据层 | Supabase Client + 类型 | `lib/supabase/` |

---

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端框架 | Next.js 14+ (App Router) | SSR + API Route 一体化 |
| 语言 | TypeScript | 全栈类型安全 |
| 样式 | Tailwind CSS | Utility-first |
| UI 组件 | shadcn/ui | Radix UI 封装 |
| 图标 | lucide-react | |
| 认证 | Supabase Auth | JWT 会话 |
| 数据库 | Supabase Postgres | 14 张表 + RLS |
| AI 模型 | DeepSeek / Claude / Kimi / 豆包 | Provider 适配器模式 |
| 部署 | Vercel | 前端 + Serverless API |

## 鉴权流程

```
用户请求 → middleware.ts
  ↓
Supabase Auth 检查 session
  ↓
未登录 → 重定向 /login
已登录 → 放行到页面/API
  ↓
API Route → Supabase Server Client
  ↓
RLS 自动过滤数据（只能查到自己的数据）
```
