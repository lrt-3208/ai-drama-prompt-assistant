## 核心接口详细设计

### 创建项目

```
POST /api/projects
```

Request:
```json
{ "name": "重生：这一次...", "synopsis": "林晚被陷害...", "genre": "复仇" }
```

Response 201:
```json
{ "id": "uuid", "name": "...", "genre": "复仇", "status": "draft", "created_at": "..." }
```

### AI 生成剧本

```
POST /api/projects/[id]/script/generate
```

Request:
```json
{ "storyInput": "林晚被陷害...", "inputMode": "story", "aiModel": "deepseek" }
```

Response 200:
```json
{
  "script": {
    "synopsis": "...", "genre": "复仇重生",
    "characters": [{ "name": "林晚", "age": 25, ... }],
    "relationships": "...", "worldview": "...",
    "plot_outline": [{ "episode": 1, "title": "雨夜重生", "summary": "..." }]
  }
}
```

### AI 提取角色资产

```
POST /api/projects/[id]/characters/generate
```

Request:
```json
{ "aiModel": "deepseek" }
```

Response 200:
```json
{
  "characters": [
    {
      "id": "uuid", "name": "林晚", "age": 25, "gender": "女",
      "face_shape": "瓜子脸", "hairstyle": "黑色长直发",
      "visual_prompt": "25岁亚洲女性，瓜子脸，黑色长直发，清冷五官..."
    }
  ]
}
```

### AI 生成图片 Prompt（上下文驱动）

```
POST /api/shots/[shotId]/prompts/generate
```

Request:
```json
{ "promptType": "image", "platform": "midjourney", "language": "en", "aiModel": "deepseek" }
```

Response 200:
```json
{
  "prompt": {
    "id": "uuid", "shot_id": "uuid",
    "prompt_type": "image", "platform": "midjourney", "language": "en",
    "current_version": {
      "id": "uuid", "content": "A 25-year-old Asian woman... --ar 16:9 --v 6",
      "version_number": 1, "is_current": true, "created_at": "..."
    }
  }
}
```

### 保存 Prompt 编辑

```
PUT /api/prompts/[id]
```

Request:
```json

```

Response 200:
```json
{
  "version": { "id": "uuid", "version_number": 2, "is_current": true, "created_at": "..." }
}
```

## 通用响应格式

```json
// 成功
{ "data": {...} }

// 失败
{ "error": { "code": "AI_GENERATION_FAILED", "message": "AI服务调用失败，请重试" } }
```

## 错误码

| Code | HTTP | 说明 |
|------|------|------|
| UNAUTHORIZED | 401 | 未登录 |
| FORBIDDEN | 403 | 无权限访问该资源 |
| NOT_FOUND | 404 | 资源不存在 |
| VALIDATION_ERROR | 400 | 请求参数校验失败 |
| AI_GENERATION_FAILED | 500 | AI 调用失败 |
| AI_TIMEOUT | 504 | AI 调用超时 |
| CONTEXT_MISSING | 400 | 上下文缺失（如资产未建立） |

## 鉴权中间件

```typescript
// middleware.ts
import { createServerClient } from '@supabase/ssr';
import { NextResponse } from 'next/server';

export async function middleware(req) {
  const res = NextResponse.next();
  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    { req, res }
  );
  const { data: { session } } = await supabase.auth.getSession();

  const protectedPaths = ['/dashboard', '/projects'];
  const isProtected = protectedPaths.some(p => req.nextUrl.pathname.startsWith(p));

  if (isProtected && !session) {
    return NextResponse.redirect(new URL('/login', req.url));
  }
  return res;
}

export const config = {
  matcher: ['/dashboard/:path*', '/projects/:path*', '/api/:path*']
};
```
