# 核心数据流

> MVP 核心数据流转路径，每个流程的输入/处理/输出明确。  
> 关联文档：[一致性系统最终设计.md](./一致性系统最终设计.md) | [../product/MVP范围冻结.md](../product/MVP范围冻结.md)

---

## 流程总览

```
创建项目 → 故事输入 → 剧本生成 → 资产建立 → 分镜生成 → Prompt 生成
                                                      ↓
                                                 用户复制 Prompt
```

---

## 1. 创建项目流程

```
用户
 ↓
填写 name / synopsis / genre
 ↓
Project（projects 表）
```

| 步骤 | 输入 | 处理 | 输出 |
|------|------|------|------|
| 用户创建项目 | name, synopsis, genre | 写入 projects 表 | project.id |

---

## 2. 故事输入流程

```
用户
 ↓
方式1：输入一句故事简介
方式2：粘贴已有故事文本
 ↓
Story（stories 表：raw_input + input_mode）
```

| 步骤 | 输入 | 处理 | 输出 |
|------|------|------|------|
| 输入故事 | raw_input, input_mode | 写入 stories 表（project_id 唯一） | story.id |

---

## 3. 生成角色流程

```
Story Context（故事原文）
 ↓
AI 分析（generateCharacters）
 ↓
Characters[]（角色资产列表，含 fixed_prompt）
 ↓
用户确认 / 编辑
 ↓
写入 characters 表
```

| 步骤 | 输入 | AI 处理 | 输出 |
|------|------|---------|------|
| AI 提取角色 | story.raw_input | 分析故事人物，生成角色资产 + fixed_prompt | characters[] |
| 用户确认 | AI 输出 | 用户编辑/增删 | 最终 characters[] |

---

## 4. 生成剧本流程

```
Story
  *
Characters
  *
Visual Style
 ↓
AI Script Generator（generateScript）
 ↓
Script（synopsis / characters / relationships / worldview / plot_outline）
 ↓
写入 scripts 表
```

| 步骤 | 输入 | AI 处理 | 输出 |
|------|------|---------|------|
| AI 生成剧本 | story + characters + style | 结构化扩写/整理 | script JSON |

> 注：角色和风格可以在剧本生成之前或之后建立，但分镜生成前必须完成。

---

## 5. 生成分镜流程

```
Script
  *
Characters
  *
Locations
  *
Visual Style
 ↓
Storyboard Generator（generateStoryboard）
 ↓
Episode → Scene → Shot
 ↓
写入 episodes + scenes + shots 表
```

| 步骤 | 输入 | AI 处理 | 输出 |
|------|------|---------|------|
| AI 生成分镜 | script + characters + locations + style | 拆解 Episode→Scene→Shot | scenes[] + shots[] |
| 场景自动建资产 | 新场景 | 自动创建 Location 资产 | locations[] |
| 镜头引用角色 | character_ids | 关联已有角色资产 | shots.character_ids |

---

## 6. 生成 Prompt 流程

```
Shot
  *
Character(s).fixed_prompt
  *
Location.fixed_prompt
  *
Visual Style.fixed_prompt
  *
Platform Template
 ↓
Prompt Engine
  ├── ContextBuilder（汇聚五重上下文）
  ├── TemplateAssembler（组装 System Prompt）
  ├── AIAdapter（调用模型）
  └── OutputProcessor（保存 + context_snapshot）
 ↓
Prompt（content + context_snapshot）
 ↓
写入 prompts + prompt_versions 表
 ↓
用户复制 → 第三方平台
```

| 步骤 | 输入 | 处理 | 输出 |
|------|------|------|------|
| ContextBuilder | shotId, platform, language | 查询 5 重上下文 | PromptContext |
| TemplateAssembler | PromptContext | 组装 system + user prompt | { system, user } |
| AIAdapter | { system, user } | 调用 AI 模型 | AI 生成文本 |
| OutputProcessor | 生成文本 + 上下文快照 | 保存 prompts + prompt_versions | prompt + version |

---

## 数据依赖链

```
projects
  └── stories（依赖 project）
  └── characters（依赖 project）
  └── locations（依赖 project）
  └── visual_styles（依赖 project）
  └── scripts（依赖 project + story + characters + style 作为 AI 输入）
  └── episodes（依赖 project）
        └── scenes（依赖 episode + location）
              └── shots（依赖 scene + character_ids）
                    └── prompts（依赖 shot + 平台模板 + 五重上下文）
                          └── prompt_versions（依赖 prompt）
```

> **开发顺序 = 数据依赖顺序**：必须先有上游数据，才能生成下游。
