> 重点解决：多镜头角色漂移问题。  
> 关联文档：[核心数据流.md](./核心数据流.md) | [../product/MVP范围冻结.md](../product/MVP范围冻结.md)

---

## 问题定义

AI 短剧最大问题：**多镜头角色漂移**。

| 漂移类型 | 表现 | 根因 |
|----------|------|------|
| 人物漂移 | 同一角色在不同镜头中外貌不同 | 每次独立描述，细节丢失 |
| 场景漂移 | 同一地点在不同镜头中布局不同 | 无固定场景描述 |
| 风格漂移 | 整片画面基调不统一 | 无全局风格约束 |

---

## 解决方案：三层固定资产

```
三层固定资产（用户在资产中心创建/编辑）
├── Character.fixed_prompt  → 锁定人物外貌
├── Location.fixed_prompt    → 锁定场景环境
└── Visual Style.fixed_prompt → 锁定影视风格
        ↓
生成 Prompt 时自动组合三层 + 镜头上下文
        ↓
所有镜头 Prompt 包含相同的角色/场景/风格描述
        ↓
用户复制到第三方平台 → 生成结果视觉一致
```

---

## 三层资产设计

### 1. Character（角色资产）

| 字段 | 说明 |
|------|------|
| name | 角色名 |
| age / gender / appearance / personality / background / clothing | 结构化属性 |
| **fixed_prompt** | 固定视觉描述（如"25岁亚洲女性，黑色长直发，清冷五官，修长身材"） |

**一致性机制**：所有引用该角色的镜头，图片 Prompt 必须包含 `fixed_prompt` 原文。

### 2. Location（场景资产）

| 字段 | 说明 |
|------|------|
| name | 场景名 |
| description / environment / time / weather / color_style | 结构化属性 |
| **fixed_prompt** | 固定场景描述（如"现代医院入口，深夜暴雨，霓虹灯倒影，冷青色调"） |

**一致性机制**：同一场景的所有镜头共享 `fixed_prompt`。

### 3. Visual Style（视觉风格）

| 字段 | 说明 |
|------|------|
| name | 风格名 |
| camera_style / color / lighting / cinematography | 结构化属性 |
| **fixed_prompt** | 固定风格描述（如"都市复仇风格，冷蓝灰色调，电影摄影，高对比光影"） |

**一致性机制**：项目级绑定，所有镜头的图片 Prompt 都附加 `fixed_prompt`。

## Prompt 生成组合规则

```
Character Context（角色 fixed_prompt）
  +
Location Context（场景 fixed_prompt）
  +
Style Context（风格 fixed_prompt）
  +
Shot Context（镜头级动态信息：动作/情绪/摄影语言）
  ↓
Prompt Engine 组装
  ↓
最终 Prompt = 固定资产描述 + 镜头动态描述 + 平台格式
```

### 组装示例（即梦 AI 中文）

```
[Character.fixed_prompt] 25岁亚洲女性，黑色长直发，清冷五官，修长身材，
[Shot 动态] 身穿被雨水打湿的白色婚纱，表情绝望而不甘，眼神坚定。
[Location.fixed_prompt] 现代医院入口，深夜暴雨，霓虹灯倒影在水洼，冷青色调。
[Shot 动态] 站立，微微抬头望向医院温暖灯光。
[Shot 摄影] 中景构图，低角度仰拍，浅景深，焦距50mm。
[VisualStyle.fixed_prompt] 都市复仇风格，冷蓝灰色调，电影摄影，高对比光影，16:9。
```

## 一致性 vs 灵活性

| 层级 | 一致性 | 灵活性 |
|------|--------|--------|
| 角色外貌 | 固定（fixed_prompt 锁定） | 服装/表情可变（镜头级） |
| 场景环境 | 固定（fixed_prompt 锁定） | 时间/天气可变（镜头级覆盖） |
| 画面风格 | 固定（项目级锁定） | 不可变 |
| 镜头摄影 | 不固定 | 每镜头独立描述 |

**原则**：资产级固定 + 镜头级灵活。

## context_snapshot 机制

每次生成 Prompt 时，保存上下文快照到 `prompts.context_snapshot`：

```json
{
  "characters": [
    { "id": "uuid", "name": "林晚", "fixed_prompt": "25岁亚洲女性..." }
  ],
  "location": { "id": "uuid", "name": "医院门口", "fixed_prompt": "现代医院入口..." },
  "visual_style": { "id": "uuid", "name": "都市复仇", "fixed_prompt": "冷蓝灰色调..." }
}
```

**用途**：
- 未来修改角色后，可追溯历史 Prompt 使用了哪个版本的角色描述
- 重新生成时可对比上下文差异
- 不依赖实时查询（即使资产被修改/删除，历史 Prompt 上下文不丢失）

## 资产编辑影响传播

| 资产编辑 | 已有 Prompt | 新生成 Prompt |
|----------|-------------|----------------|
| 编辑角色 fixed_prompt | 不自动更新（context_snapshot 保留历史） | 应用新描述 |
| 编辑场景 fixed_prompt | 不自动更新 | 应用新描述 |
| 切换项目视觉风格 | 不自动更新 | 应用新风格 |

**设计决策**：不自动传播。用户需手动重新生成下游 Prompt，避免覆盖已编辑内容。
