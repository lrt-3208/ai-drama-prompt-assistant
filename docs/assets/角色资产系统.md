# 角色资产系统（Character）

> 角色资产是创作资产中心的核心之一，用于锁定人物外貌一致性。  
> 关联文档：[场景资产系统.md](./场景资产系统.md) | [资产引用机制.md](./资产引用机制.md)

---

## 设计目标

- 每个角色拥有**固定视觉描述 Prompt**（`visual_prompt`）
- 图片 Prompt 生成时自动引用角色资产，保证跨镜头人物外貌一致
- 角色资产可手动编辑、AI 自动提取、手动创建

---

## 字段定义

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | uuid | 是 | 主键 |
| project_id | uuid | 是 | 所属项目（FK → projects） |
| name | text | 是 | 角色名称，如"林晚" |
| age | int | 否 | 年龄，如 25 |
| gender | text | 否 | 性别：男/女 |
| face_shape | text | 否 | 脸型，如"瓜子脸" |
| hairstyle | text | 否 | 发型，如"黑色长直发" |
| hair_color | text | 否 | 发色，如"黑色" |
| body_type | text | 否 | 身材，如"修长身材" |
| clothing_style | text | 否 | 服装风格，如"白色婚纱/职业套装" |
| personality | text | 否 | 性格描述 |
| background | text | 否 | 背景故事 |
| visual_prompt | text | 是 | **固定视觉描述 Prompt**（核心字段） |

| created_at | timestamptz | 是 | 创建时间 |
| updated_at | timestamptz | 是 | 更新时间 |

## visual_prompt 生成规则

`visual_prompt` 是角色资产的**核心字段**，由 AI 根据结构化字段自动生成。

**生成逻辑**：
```
{age}岁{gender}{nationality}{face_shape}，
{hair_color}{hairstyle}，
{五官特征}，
{body_type}，
{clothing_style}，
{visual_style.style_prompt 中的风格关键词}
```

**示例**：
```
25岁亚洲女性，瓜子脸，黑色长直发，清冷五官，修长身材，白色婚纱，电影写实风格
```

**生成时机**：
1. AI 从剧本提取角色时自动生成
2. 用户编辑角色字段后可手动"重新生成 visual_prompt"
3. 用户可直接手动编辑 visual_prompt

## 角色与镜头关系

```
characters (1) ──── (N) shots（多对多，通过 shots.character_ids jsonb）
```

- 一个角色可出现在多个镜头中
- 一个镜头可涉及多个角色
- `shots.character_ids` 存储 JSON 数组：`["uuid-1", "uuid-2"]`

**Prompt 生成时**：Prompt Engine 通过 `character_ids` 查询角色资产，将 `visual_prompt` 拼入图片 Prompt。

## AI 提取流程

`generateCharacters(script)`:

1. 从剧本 `characters[]` 提取人物列表
2. 为每个人物扩展视觉细节（脸型/发型/身材等）
3. 生成 `visual_prompt`
4. 写入 `characters` 表

**剧本人物输入**：
```json
{
  "name": "林晚",
  "age": 25,
  "gender": "女",
  "personality": "冷静、坚韧",
  "background": "重生复仇者",
  "appearance": "长发、气质清冷、五官精致"
}
```

**AI 输出角色资产**：
```json
{
  "name": "林晚",
  "age": 25,
  "gender": "女",
  "face_shape": "瓜子脸",
  "hairstyle": "黑色长直发",
  "hair_color": "黑色",
  "body_type": "修长身材",
  "clothing_style": "白色婚纱/职业套装",
  "personality": "冷静、坚韧",
  "background": "重生复仇者",
  "visual_prompt": "25岁亚洲女性，瓜子脸，黑色长直发，清冷五官，修长身材，电影写实风格"
}
```

## 角色资产管理操作

| 操作 | 说明 |
|------|------|
| AI 自动提取 | 剧本生成后一键提取所有角色 |
| 手动创建 | 用户在资产中心新增角色 |
| 编辑 | 修改字段后可重新生成 visual_prompt |
| 删除 | 删除角色（不影响已有镜头引用，但 Prompt 生成时该角色描述为空） |
| 引用查看 | 查看该角色被哪些镜头引用 |
