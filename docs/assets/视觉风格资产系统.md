# 视觉风格资产系统（Visual Style）

> 视觉风格资产用于锁定全片画面基调一致性。  
> 关联文档：[角色资产系统.md](./角色资产系统.md) | [资产引用机制.md](./资产引用机制.md)

---

## 设计目标

- 每个项目绑定一个**视觉风格**（Visual Style）
- 风格拥有固定 `style_prompt`，项目内所有镜头的图片 Prompt 都附加该描述
- 保证全片画面基调统一（色调/光影/摄影/比例）

---

## 字段定义

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | uuid | 是 | 主键 |
| project_id | uuid | 是 | 所属项目（FK → projects，一对一） |
| name | text | 是 | 风格名称，如"都市复仇短剧风格" |
| photography_style | text | 否 | 摄影风格，如"电影摄影，低角度仰拍" |
| lens_language | text | 否 | 镜头语言，如"50mm，浅景深" |
| color_scheme | text | 否 | 色彩方案，如"冷蓝灰色调" |
| lighting | text | 否 | 光影，如"高对比光影，体积光" |
| aspect_ratio | text | 否 | 画面比例，如"16:9" |
| visual_references | text | 否 | 视觉参考，如"《黑暗荣耀》质感" |
| style_prompt | text | 是 | **固定 Style Prompt**（核心字段） |
| created_at | timestamptz | 是 | 创建时间 |
| updated_at | timestamptz | 是 | 更新时间 |

---

## style_prompt 生成规则

```
{name}，
{color_scheme}，
{photography_style}，
{lighting}，
{lens_language}，
{aspect_ratio}
```

**示例**：
```
都市复仇短剧风格，冷蓝灰色调，电影摄影，高对比光影，50mm镜头，16:9
```

---

## 视觉风格与项目关系

```
projects (1) ──── (1) visual_styles（一对一，通过 projects.visual_style_id）
```

- 一个项目绑定一个视觉风格
- 项目内所有镜头的图片 Prompt 都包含该 `style_prompt`
- 切换风格需手动触发已有 Prompt 重新生成

---

## AI 推荐流程

视觉风格可由 AI 根据剧本类型自动推荐：

`generateVisualStyle(genre)`:

1. 根据剧本 genre 匹配预设风格模板
2. 生成完整风格字段 + `style_prompt`
3. 用户可编辑调整

**类型 → 风格映射（预设）**：

| 类型 | 风格 | 色调 | 摄影参考 |
|------|------|------|----------|
| 复仇/重生 | 都市复仇短剧 | 冷蓝灰 | 《黑暗荣耀》 |
| 甜宠 | 明亮甜宠风格 | 暖粉橙 | 《你是我的荣耀》 |
| 穿越 | 古风穿越风格 | 暖金/青绿 | 《庆余年》 |
| 悬疑 | 暗黑悬疑风格 | 冷暗绿 | 《隐秘的角落》 |
| 都市 | 现代都市风格 | 自然色 | 《三十而已》 |

---

## 视觉风格管理操作

| 操作 | 说明 |
|------|------|
| AI 推荐 | 根据剧本类型自动推荐风格 |
| 手动创建 | 用户自定义风格 |
| 编辑 | 修改字段后可重新生成 style_prompt |
| 切换 | 项目切换视觉风格（已有 Prompt 不自动更新） |
