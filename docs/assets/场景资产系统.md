# 场景资产系统（Location）

> 场景资产用于锁定同一地点在不同镜头中的环境一致性。  
> 关联文档：[角色资产系统.md](./角色资产系统.md) | [资产引用机制.md](./资产引用机制.md)

---

## 设计目标

- 每个场景拥有**固定视觉描述 Prompt**（`visual_prompt`）
- 同一场景在不同镜头中共享该描述，保证环境元素一致
- 场景资产可由 AI 从剧本/分镜提取，也可手动创建

---

## 字段定义

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | uuid | 是 | 主键 |
| project_id | uuid | 是 | 所属项目（FK → projects） |
| name | text | 是 | 场景名称，如"医院门口" |
| location_type | text | 否 | 地点类型：户外/室内/建筑入口 等 |
| environment | text | 否 | 环境描述，如"暴雨、霓虹灯倒影" |
| fixed_elements | text | 否 | 固定元素，如"医院招牌灯光、水洼、雨幕" |
| time | text | 否 | 默认时间，如"深夜" |
| weather | text | 否 | 默认天气，如"暴雨" |
| color_tone | text | 否 | 色调，如"冷青色" |
| layout | text | 否 | 空间布局描述 |
| visual_prompt | text | 是 | **固定场景描述 Prompt**（核心字段） |
| reference_image_url | text | 否 | 参考图片URL（扩展预留） |
| created_at | timestamptz | 是 | 创建时间 |
| updated_at | timestamptz | 是 | 更新时间 |

---

## visual_prompt 生成规则

```
{location_type}{name}，
{environment}，
{fixed_elements}，
{color_tone}色调，
电影氛围
```

**示例**：
```
现代医院入口，深夜暴雨，霓虹灯倒影在水洼，医院招牌灯光、雨幕，冷青色调，电影氛围
```

---

## 场景与镜头关系

```
locations (1) ──── (N) scenes（通过 scenes.location_id 外键）
                        ↓
                   scenes (1) ──── (N) shots
```

- 一个场景资产可被多个 Scene 引用
- 一个 Scene 关联一个 Location
- Scene 下的所有 Shot 共享该 Location 的 visual_prompt

**引用链**：`shot.scene_id → scene.location_id → location.visual_prompt`

**镜头级覆盖**：Shot 可有独立的 `environment` 字段覆盖场景默认环境（如同一场景白天/夜晚不同）。

## AI 提取流程

场景资产在分镜生成时由 AI 自动提取：

1. `generateStoryboard()` 拆解 Scene 时，为每个新场景创建 Location 资产
2. 提取场景的地点/时间/天气/环境，生成 `visual_prompt`
3. 已存在的同名场景自动复用（避免重复创建）

**分镜 Scene 输出**：
```json
{
  "scene_number": 1,
  "location_name": "医院门口",
  "location": {
    "location_type": "户外/建筑入口",
    "environment": "暴雨、霓虹灯倒影",
    "fixed_elements": "医院招牌灯光、水洼、雨幕",
    "time": "深夜",
    "weather": "暴雨",
    "color_tone": "冷青色",
    "visual_prompt": "现代医院入口，深夜暴雨，霓虹灯倒影在水洼，冷青色调，电影氛围"
  },
  "shots": [...]
}
```

## 场景资产管理操作

| 操作 | 说明 |
|------|------|
| AI 自动提取 | 分镜生成时自动创建场景资产 |
| 手动创建 | 用户在资产中心新增场景 |
| 编辑 | 修改字段后可重新生成 visual_prompt |
| 删除 | 删除场景资产（引用该场景的 Scene 的 location_id 置空） |
| 复用检查 | 同项目内同名场景自动复用，不重复创建 |
